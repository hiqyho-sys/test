04 / Практика

За каждым грузом —
задача бизнеса.

Проекты, опубликованные компанией: от защиты интересов клиента до организации сложных цепочек поставки.

ПРОЕКТ / 01

Защита товарных знаков

Сопровождение включения товарных знаков в ТРОИС для защиты правообладателей.

ПРОЕКТ / 02

Контрейлерный эксперимент

Участие в тестовой перевозке автомобилей с грузом по железной дороге и анализ документальных и организационных препятствий.

ПРОЕКТ / 03

Споры о кодах, стоимости и НДС

Подготовка доказательств, экспертиз и правовой позиции для обжалования таможенных решений.

ПРОЕКТ / 04

Оборудование в уставный капитал

Корпоративное и таможенное сопровождение ввоза оборудования и тягачей как вклада в капитал с применением предусмотренного освобождения.

ПРОЕКТ / 05

Лицензионные платежи

Судебная защита по включению роялти в таможенную стоимость.

ПРОЕКТ / 06

Разобранное комплексное оборудование

Комплект документов для классификации оборудования, ввозимого отдельными партиями: завод керамической плитки, угольный комплекс и зерновой терминал.

ПРОЕКТ / 07

Предварительные решения ТН ВЭД

Подготовка технических документов и взаимодействие с ФТС по спорным кодам сложного оборудования, электроники, химических веществ и пищевых добавок.

ПРОЕКТ / 08

Компоненты для завода

Организация таможенного склада в 2017 году для хранения и дробления партий компонентов производителя бытовой техники и электроники.

ПРОЕКТ / 09

Склад для парфюмерной сети

Дорожная карта создания закрытого таможенного склада на существующей территории и запуска маркировки импортной косметики.
