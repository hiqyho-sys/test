# Орбита — ТЭК Карго Транс, Крёкшино

Сайт: https://hiqyho-sys.github.io/test/orbit/

Восемь страниц, интерактивный шар с точкой Крёкшино, постоянный анимированный фон и анимация ночного терминала.

## Структура

- index.html — главная
- services.html — услуги
- terminal.html — терминал Крёкшино
- company.html — компания
- practice.html — организация работы
- prices.html — тарифы
- documents.html — документы
- contacts.html — контакты
- orbit-assets/ — локальные стили, скрипты, шрифты и изображение
- orbit-documents/ — три PDF-документа
- FONT_LICENSE.txt — сведения о шрифтах

Сайт опубликован в отдельной папке orbit существующего репозитория. Все ссылки относительные и поддерживают путь /test/orbit/. Для обновления заменяйте файлы в этой папке и сохраняйте commit в main. Действующий GitHub Pages опубликует изменения автоматически. Node.js и сборка не нужны. Кнопки обращения используют телефон и электронную почту.
